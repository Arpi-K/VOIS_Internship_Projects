# VOIS Internship Projects

This repository contains the **Minor Project** and **Major Project** completed as part of the **VOIS and Vodafone Idea Foundation’s - VOIS for Tech Program on DATA ANALYTICS by Edunet Foundation**.

Both projects focus on **data analysis using Python**, with the analysis performed in **Jupyter Notebooks using VS Code**.

## 📁 Repository Structure

```text
VOIS_Internship_Projects/
│
├── Major Project/
│   ├── agriculture_data_analysis.ipynb
│   └── seasonal_agriculture_performance_dataset.csv
│
└── Minor Project/
    ├── Car Market Trends Analysis with Car Dekho Data.csv
    └── Car_data_analysis.ipynb
```

## 🛠️ Tools & Technologies

* Python
* Jupyter Notebook
* VS Code
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 📊 Projects

### Minor Project

Contains the Minor Project completed during the internship, including data exploration, cleaning, analysis and visualization using Python on the car sales dataset.

### Major Project – Seasonal Agriculture Performance Analysis

Analyzes agricultural data to identify **seasonal patterns, trends, relationships and variations** in agricultural performance.

The analysis covers areas such as:

* Seasonal and crop-wise performance
* Yield analysis
* Environmental factors
* Farming practices
* Resource usage
* Revenue and profit
* Data visualization and statistical analysis

## 🎯 Objective

The main objective of these projects is to apply **Python-based data analysis techniques** to explore datasets, identify meaningful patterns and generate data-driven insights.

## 💻 Development Environment

All analysis and visualizations were created using **Python in Jupyter Notebook through VS Code**.
